# Артефакты COLONY v1.14.1

Четыре отдельных изображения созданы встроенным imagegen. Исходники визуально проверены; в проект сохранены прозрачные WebP 512×512, суммарно около 240 КиБ. Изображения не обрезаются и отображаются с сохранением пропорций. Первичные PNG генерации остаются вне репозитория. CLI и отдельный API-ключ не использовались.

## Задание для набора

Тип: stylized-concept, предметные изображения для интерфейса мобильной игры COLONY. Лунная научная база, объёмные читаемые силуэты, белая керамика, графитовый металл, небольшие янтарные сигнальные огни. Прозрачный фон, один предмет целиком, безопасное поле вокруг краёв, одинаковое направление света. Без текста, эмодзи, логотипов и водяных знаков. Отдельное изображение для каждого предмета:

- **Фрагмент сигнала:** бирюзовая кристаллическая структура с повторяющимися светящимися информационными дорожками в небольшом держателе.
- **Неизвестный сплав:** компактное бронзовое многогранное ядро неизвестного композита в керамическом и графитовом корпусе.
- **Звёздная карта:** голубая голографическая схема неизвестной звёздной системы над компактным навигационным проектором.
- **Квантовая линза:** фиолетовая оптическая линза с концентрическими светящимися кольцами в научном керамическом и графитовом узле.

# COLONY — Economy v1.0 Beta

v1.0 intentionally does not materially change the v0.9 resource economy. The objective is to test the existing economy with real users instead of invalidating earlier balancing work immediately before launch.

Operational systems introduced in v1.0 do not create tradable resources:
- beta codes grant access only;
- feedback grants no reward;
- maintenance grants no compensation automatically;
- Stars purchase recovery only restores an already-paid entitlement;
- rate limiting has no gameplay reward or cost.

For the first beta, balance changes should be made only after observing real median resource balances, City Score progression, contract completion, market prices and sink/faucet telemetry.

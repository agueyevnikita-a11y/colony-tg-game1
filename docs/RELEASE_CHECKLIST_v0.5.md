# Release checklist v0.5

- [ ] Применена `005_v0_5.sql` после миграций v0.2–v0.4.
- [ ] Два тестовых пользователя могут вступить в один альянс.
- [ ] Создание списывает ровно 5 000 кредитов.
- [ ] HQ1 не может вступить; HQ2 может вступить; HQ3 может создать.
- [ ] Вклад не может увести ресурс ниже нуля.
- [ ] Вклад ограничивается остатком цели этапа.
- [ ] Одновременные вклады не переполняют этап благодаря блокировке project row.
- [ ] Награды этапа получают только участники выше личного порога AP.
- [ ] После выхода действует 24h cooldown.
- [ ] Owner с другими участниками не может выйти.
- [ ] Deep link `ally_<CODE>` подставляет код, но не вступает автоматически.
- [ ] Stars не фигурируют в API вкладов и Alliance Score.
- [ ] Player/Alliance leaderboards возвращаются и отображаются.
- [ ] `npm run typecheck` и `npm run build` проходят в CI/deploy-среде.

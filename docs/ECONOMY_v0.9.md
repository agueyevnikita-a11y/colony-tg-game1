# COLONY — Economy v0.9

Основная производственная экономика v0.8 не меняется. v0.9 добавляет только небольшой retention faucet через ежедневную серию входов.

Максимум одного полного семидневного цикла: **💰3800 + 💎10**. Это 543 кредита и 1.43 кристалла в среднем в сутки при непрерывной активности. Награды не масштабируются с HQ, Premium или Stars и потому не создают дополнительного pay-to-win эффекта.

Feature flags не удаляют и не компенсируют ресурсы: они только временно запрещают новые действия соответствующей механики.

# COLONY — Economy Notes v0.8

v0.8 does not add a new monetized power layer.

## Tutorial injection
The onboarding gives a one-time package of basic resources, credits, crystals and one cosmetic title. The package is designed to remove the early solo-progression dead end before HQ2, not to fund mid-game progression.

The tutorial does **not** grant Science, Premium, market-only advantages, alliance points or seasonal ranking points.

## Notification economy impact
Telegram notifications have no resource or speed bonus. They only inform a player that a timer already completed.

## Admin monitoring
During the closed test, watch:

- median credits and resource balances by day;
- market fee sink per day;
- NPC-contract resource destruction;
- tutorial resource injection versus normal production;
- Stars purchases separately from the game economy;
- suspicious activity as a manual-review queue only.

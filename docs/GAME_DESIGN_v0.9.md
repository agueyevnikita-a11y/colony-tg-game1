# COLONY — Game Design v0.9

## Цель версии
v0.9 превращает технически готовый MVP в закрытую бету, где игрок получает персональную идентичность, ежедневный повод вернуться и системный канал сообщений, а команда получает средства безопасно включать/выключать рискованные функции без нового релиза.

## Профиль колонии
При первом входе игрок обязан выбрать название колонии длиной 3–24 символа. Короткое описание необязательно и ограничено 80 символами. Название показывается в публичном городе, рейтингах и социальных экранах; Telegram-имя остаётся служебным fallback.

## Серия входов
Серия увеличивается один раз в календарный день. Пропуск дня сбрасывает текущую серию до 1, но рекорд сохраняется. Награды образуют семидневный цикл и намеренно малы относительно экономики:

| День | Награда |
|---|---|
| 1 | 💰200 |
| 2 | 💰300 |
| 3 | 💰400 + 💎2 |
| 4 | 💰500 |
| 5 | 💰600 + 💎3 |
| 6 | 💰800 |
| 7 | 💰1000 + 💎5 |

Награда забирается вручную один раз в день. Она помогает retention, но не заменяет основную экономику.

## Inbox
Внутриигровый inbox хранит системные сообщения. В v0.9 туда попадают приветствие закрытой беты, завершение базового обучения, ежедневные награды и подтверждения Stars-покупок. Сообщения не содержат игровых ресурсов напрямую: выдача награды происходит в соответствующей транзакции, inbox лишь фиксирует событие.

## Feature flags
Функции `market`, `alliances`, `expeditions`, `stars_shop`, `notifications` и `closed_beta_banner` управляются серверными флагами. Для каждого флага доступны `enabled` и rollout 0–100%. Распределение пользователя в rollout детерминировано по его внутреннему UUID и ключу флага. Серверные action API дополнительно проверяют флаг для рынка, альянсов, экспедиций и Stars-магазина.

## Error telemetry
Клиент отправляет только сообщение ошибки, stack и path. Сервер отдельно пишет ошибки session/webhook/notification delivery. Ошибки не используются для автоматических санкций против игроков.

## Closed beta UX
На всех тестовых аккаунтах отображается пометка закрытой беты. Feature flags позволяют остановить нестабильную механику без удаления данных. Профиль можно менять после первого запуска через раздел «Связи».
